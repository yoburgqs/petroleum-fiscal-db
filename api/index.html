Petroleum Fiscal Intelligence Platform — API

Static JSON API. No authentication required. CORS-enabled via GitHub Pages.

← Back to Platform

Base URL

https://yoburgqs.github.io/petroleum-fiscal-db/api/v1/

Endpoints

GET /countries.json
All country summaries with DCF government take at 4 oil price levels ($50, $75, $100, $125/bbl).
Try it →
GET /mechanics.json
Summary by fiscal mechanic type (Concession, PSC, TSC, PRRT, RSC, Buy-back, Gross Split).
Try it →
GET /country/{name}.json
Full country detail: DCF results by price, key fiscal facts, contract list (up to 500 contracts).
Example: v1/country/norway.json | v1/country/united_kingdom.json | v1/country/iraq.json

Example: Fetch Norway DCF Data

fetch('https://yoburgqs.github.io/petroleum-fiscal-db/api/v1/country/norway.json')
  .then(r => r.json())
  .then(d => {
    console.log('Norway take @$75:', d.dcf_by_price['75'].govt_take_pct + '%');
    console.log('Contracts:', d.contracts.length);
  });

Coverage

  • 71,561 petroleum contracts across 211 countries
  • 283,990 DCF results (4 price scenarios × ~71K contracts)
  • 6 fiscal mechanics modeled
  • Per-country API files: top 50 countries by contract count

v1/schema.json

Methodology

DCF uses a standardized greenfield project profile: 25-year horizon, peak 50 MBD production, $500M capex, 10% discount rate, end-of-year cashflows. Results are averages across all modeled contracts in each country.

Data sources: NRGI Resource Governance Index, SODIR (Norway), NSTA (UK), EY/KPMG Tax Guides 2025, operator disclosures.
